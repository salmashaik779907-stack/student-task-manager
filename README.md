# ✿ StudyMate – Student Task Manager

## 📌 Introduction

**StudyMate** is a simple and user-friendly Student Task Manager developed using HTML, CSS, and JavaScript.

It is designed to help students organize their daily academic activities, manage study tasks, and track their progress. Students can add tasks, mark them as completed, and delete tasks when they are no longer needed.

StudyMate provides a clean and attractive dashboard that makes task management simple and convenient.

## 🎯 Project Objectives

- To help students organize their academic tasks.
- To improve time management and productivity.
- To keep track of pending and completed tasks.
- To provide a simple and easy-to-use interface.
- To encourage students to maintain a consistent study routine.

## ✨ Features

- **Add Tasks:** Add assignments, study activities, and other tasks.
- **Complete Tasks:** Mark tasks as completed.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Task Statistics:** View total, pending, and completed task counts.
- **Enter Key Support:** Add tasks by pressing the Enter key.
- **Empty State Message:** Displays a friendly message when there are no tasks.
- **User-Friendly Interface:** Simple and attractive dashboard design.
- **Responsive Styling:** CSS styling supports different screen sizes.

## 🚀 How to Run the Project Locally

Follow these steps to run StudyMate on your computer:

1. Download or clone the project repository.
2. Extract the downloaded ZIP file if necessary.
3. Open the `student-task-manager` project folder.
4. Locate the `index.html` file.
5. Double-click `index.html` or open it using any modern web browser.
6. The StudyMate application will open in your browser.

**Note:** No additional software or installation is required to run this basic frontend project.

## 🤝 GitHub Collaboration Workflow

Our project uses GitHub for version control and team collaboration.

### 1. Issues

GitHub Issues are used to report bugs, suggest improvements, and assign project-related tasks.

### 2. Branches

Each team member can create a separate branch to work on assigned tasks without directly modifying the main branch.

Example:

```bash
git checkout -b feature/project-documentation
```

### 3. Commits

Commits record changes made to the project with meaningful messages.

Example:

```bash
git add README.md
git commit -m "Update project documentation"
```

### 4. Pull Requests

After completing the assigned work, team members create a Pull Request to propose merging their branch into the main branch.

### 5. Merging

The team leader or an authorized reviewer checks the Pull Request. After approval, the changes are merged into the main branch.

### Collaboration Flow

```text

      ↓
```
